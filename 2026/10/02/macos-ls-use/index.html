macOS ls 命令常用组合

2026-10-02
#Unix #macOS
命令 用途
ls 查看当前目录
ls -l 显示详细信息
ls -lh 详细信息 + 易读文件大小
ls -a 显示所有文件，包括隐藏文件
ls -Alh 隐藏文件 + 详细信息 + 易读大小
ls -lht 按修改时间排序，最新在前
ls -lhtr 按修改时间排序，最新在后
ls -lhS 按文件大小排序，最大在前
ls -lhSr 按文件大小排序，最小在前
ls -lT 显示完整修改时间
ls -ld DIR 查看目录本身的信息和权限
ls -R 递归显示所有子目录
ls -F 标记文件类型，如 /、*、@
ls -G macOS 彩色显示
ls -leO@ 查看 ACL、文件 flags 和扩展属性
