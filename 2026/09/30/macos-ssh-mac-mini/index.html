macOS 用 ssh 远程 Mac mini

2026-09-30
#Unix #macOS

1. 前言

在一台 macOS 上，通过 ssh 远程登陆 Mac mini 的步骤。

2. 步骤

  1. 打开 Mac mini 的 Remote Login 设置：「Settings」—「General」—「Sharing」—「打开Remote Login」。在一台 macOS 系统的终端，输入 ssh name@IP，即可远程登陆 Mac mini

  2. 在 macOS 上设置 SSH 公钥登陆 Mac mini 服务器，见：macOS终端SSH公钥登陆服务器

  3. 设置 Mac mini 的 SSH 服务端设置：

sudo vim /etc/ssh/sshd_config

加入命令：

PasswordAuthentication no
KbdInteractiveAuthentication no
PubkeyAuthentication yes

Include /etc/ssh/sshd_config.d/*

AuthorizedKeysFile .ssh/authorized_keys

重启 sshd ：

sudo launchctl kickstart -k system/com.openssh.sshd
