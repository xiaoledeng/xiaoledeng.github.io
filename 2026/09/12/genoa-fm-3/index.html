介绍

在热那亚（Genova），喜欢古典音乐的话，可以重点收藏：

95.1 / 98.9 / 99.9 MHz — Rai Radio 3

Rai Radio 3 是意大利国家广播电视公司 RAI 旗下的文化广播频道，主要内容包括古典音乐、歌剧、爵士、文学、艺术、历史和科学。它不是全天纯古典音乐台，而是以古典音乐与人文文化为核心的综合频道。

其中最值得关注的是 Radio3 Suite，节目涵盖交响乐、室内乐、歌剧、爵士及音乐会现场；Il Cartellone 还会播出和介绍意大利及国际重要音乐机构的演出。

如果希望听更纯粹的古典音乐，可以通过 RAI 的 在线广播页面 收听 Rai Radio 3 Classica。

核心
